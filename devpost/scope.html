MemoryGarden

Where Memories Bloom.

A personal, illustrated garden where meaningful memories become flowers—and revisiting your stories feels like exploring a peaceful little world.

A lightweight planning companion. scope.md is the primary document. This page does not settle the application's visual design; those decisions belong in the PRD.

Who it's for

A moment worth keeping.

A university student saves an evening with friends, a first day, or a personal achievement—moments that otherwise get buried in galleries or scattered notes.

The distinctive idea: the memory blooms into a lasting flower, and exploring the garden brings its story back.

What it should feel like

A personal sanctuary.

A cozy 2D storybook garden. Soft pastels, warm sunlight, gentle movement, consistent illustrations, and an inviting journal.

Happy, bittersweet, and difficult memories all belong. Suggestions must never force a positive interpretation.

The interactive garden and seed-to-flower animation are required product experiences. Garden, flowers, journal, typography, motion, and controls must feel like parts of the same illustrated world. Polish and reliability take priority over more features.

One complete experience

From a story to a growing garden.

Follow the main path below. AI is optional; both routes return to review. On narrow screens, scroll the diagram horizontally.

  1. 0–10 seconds

    Enter

    Sunlight, gentle swaying plants, subtle butterflies, and a clear “Plant a Memory” invitation.

  2. 10–25 seconds

    Write

    A journal-style space for a fictional evening with university friends. Optionally add a photo.

  3. 25–35 seconds

    Review

    Explicitly request AI suggestions. Change the title, theme, and flower before confirming.

  4. 35–45 seconds

    Bloom

    The journal closes gently. A seed settles, sprouts, and becomes the chosen flower.

  5. 45–60 seconds

    Revisit

    Click the flower to read its story, date, theme, and optional photo. Close it; the flower remains.

The signature moment: a real memory becomes a beautiful flower in a garden that feels personal. “An Evening to Remember” and lavender illustrate a suggestion; exact AI wording is not fixed.

Protect the core experience

Small in scope. Carefully finished.

Expand the sections to review what belongs in this version and why other ideas wait.

Now One complete memory-to-flower journey
  • A responsive illustrated 2D garden and a small, carefully designed flower library.
  • Journal-style memory capture and reading, with an optional photo.
  • Optional AI suggestions; manual selection of title, emotional theme, and flower.
  • Editable planting details, a satisfying seed-to-bloom animation, and click-to-revisit flowers.
  • Same-browser persistence and individual memory deletion.
  • Consistent assets, thoughtful typography, ambient movement, and reliable interactions across desktop and mobile.
Later Surprise rediscovery

Let the garden reveal an older memory after the core journey is complete and polished. For this version, users rediscover memories by clicking flowers.

Explicitly cut Keep the build focused and personal
  • Accounts, authentication, cloud memory storage, and cross-device sync: same-browser persistence proves the concept with less infrastructure.
  • Public profiles, sharing, followers, and community: the focus is personal reflection.
  • Analytics tracking and unnecessary collection: these do not support the core journey.
  • 3D and per-memory image generation: curated 2D assets protect visual consistency and build simplicity.
  • Complex encryption or backend infrastructure beyond secure AI access: outside this browser-local proof of concept.
Personal memories, explicit choices

Privacy & user control.

Saved in this browser

Memories remain after refresh and reopening in the same browser, provided site data has not been cleared. There are no accounts or cloud memory database.

Use storage appropriate for photos, such as IndexedDB. Users can delete individual memories; cross-device access and recovery are outside this version.

AI only when invited

Before the first analysis, clearly explain that requesting suggestions sends the memory text to an external AI service. Never send text automatically while typing.

Users can choose details without AI, edit every suggestion, and keep their original story unchanged unless they edit it. API keys stay out of frontend code; secure integration is chosen in the technical spec.

Browser-local storage does not mean all processing happens on-device. No analytics tracking or public profiles. Demonstrations use fictional memories.

The finish line

What proves it works?

A complete, reliable journey

  • Write → request suggestions → review → plant → bloom → revisit works end to end.
  • Manual planting and individual deletion work.
  • The saved garden survives refresh and reopening while site data remains available.
  • The memory card shows the original story, title, date, theme, and photo when provided.
  • Desktop and mobile feel cohesive; difficult memories are treated with the same care as happy ones.

A demonstrable passion project

Prepare a short demo video and a public GitHub repository with fictional sample content and secret-free configuration. Deployment is optional.

Main schedule risk: illustration and animation polish within the curriculum's 2–4 hours of active work. The technical plan must assess feasibility against this quality bar before implementation.
